# 星間通信局

小学3〜6年生向けの英語学習サイト。`index.html` を開くだけで使えます。
GitHub Pagesにもそのまま配置できます。配信時の外部ライブラリやビルドは不要です。

## 収録内容

- 語彙200語、20テーマ。絵・音声・フラッシュ・聞き取りクイズ。曜日、月、服、のりもの、教室の物などを追加しています。
- フォニックス44項目。基礎26文字、二重字・ブレンド、Magic e、母音チーム、単語くみたて。
- Small Talk 9テーマ。A/B役割交代と複数往復の対話。学校生活、夏の思い出、道案内、買い物を含みます。
- 表現24枚。発見と場面練習を別々に記録し、テーマごとにバッジを獲得します。

600〜700語をすべて収録した版ではありません。教科書に限定しない基礎教材です。

## 追加した学習・授業機能

- 4課共通の「今日の復習」。獲得済みの星・カードと、別の日にも確認できた定着状態を区別します。同じ日の反復だけでは定着扱いになりません。
- 4課を横断する短いミッション。途中終了できます。最後の発話は児童による自己確認で、発音の自動採点ではありません。
- 自分の好み・生活時刻・教科・経験を使ったペア交信。質問、返答、反応、役割交代、振り返りを行います。実際の相手の声は録音・送信しません。
- 先生用管制室の授業パック。学年、単語テーマ、信号レベル、対話テーマ、表現の場面、問題数、時間のめやす、字幕を保存・共有できます。教科書名・単元名は先生が任意に登録します。特定の版への厳密な対応を保証する機能ではありません。
- 共有端末で最大40人の通信士を切り替え。各人の学習記録を分離します。切り替えは認証ではなく、同じ端末を使う人は先生用画面にもアクセスできます。
- 先生が最大100件の記録JSONを読み込む学級一覧。復習・定着件数の確認、学年・復習対象による絞り込み、集計CSVの出力ができます。読み込んだ記録はスナップショットであり、リアルタイム同期ではありません。
- 単語・表現のCSV、印刷カード、Kahoot用TSV。テーマ別または全テーマを選べます。

本部から復習・ミッション・ペア交信、右上の人物ボタンから通信士切り替え、歯車から先生用管制室へ進めます。

## 記録と授業設定

記録は端末のlocalStorageに保存します。既存v1の獲得記録を読み込みます。
獲得した星・ランク・バッジと、現在の復習状況を分けて保持します。
復習間隔は別の日の正解で1・3・7・14・30日、誤答時は10分です。

4課共通の定着記録は、別の日の正解で復習間隔を延ばします。誤答後も獲得済みの星・ランク・バッジは消えません。
Small Talk・ペア交信・ミッションの発話記録は自己申告の練習記録です。教科の評定や発音の客観評価としては使用しないでください。

先生用設定から再生速度・英語字幕・A/Bの声・投影モードを変更できます。
JSONで記録を書き出し、別端末に読み込めます。読み込みは内容確認後に現在の記録を置き換えます。
児童別の記録を書き出し、先生の端末で複数ファイルをまとめて読み込めます。新しい形式では通信士IDを保持し、同じ通信士の新しい記録で一覧を更新します。
学級記録、保存した授業、音声確認状況は先生の端末内に保存します。学級一覧に自動で児童端末のデータが送信されることはありません。
個人情報を避け、よび名・番号などで運用してください。ブラウザのデータ消去に備えて、児童の記録を定期的に書き出してください。

## 音声

フォニックスのWAV音声は、IPAを明示してMicrosoft Zira Desktopで生成し、HTML内に埋め込んでいます。
フォニックス音声の再生にネット接続は不要です。単語・会話にはブラウザのWeb Speech APIを使います。
声の種類と再生品質は端末によって異なります。先生用設定に全フォニックス音声の確認ボタンがあります。
合成音声であり、人による録音素材ではありません。

先生用管制室の教材タブで、各信号の音声確認と音声ファイルの差し替えができます。
差し替え音声は1MB以内、0.05〜15秒で、デコード可能かつ無音ではないファイルを受け付けます。保存先はこの端末のIndexedDBです。
確認済み表示は先生が付ける端末上のチェックで、専門家による監修済みを意味しません。利用許諾のある素材を使用してください。
差し替え音声は進捗JSONに含まれず、別端末では再登録が必要です。
本人のよび名を含むペア交信の参考音声は端末内の英語音声だけを使用します。端末内音声がない場合は、再生せず文字・対面発話で練習します。

## 公開・オフライン

HTML単体で開く方法は引き続き使えます。GitHub Pagesで公開する場合はリポジトリ直下を配信してください。
`manifest.webmanifest`、`sw.js`、`station.svg`を含めてHTTPSで配信すると、初回読み込み後に教材をオフラインで再度開けます。
授業共有リンクには児童の進捗・よび名を含めません。HTMLを直接開いた場合のリンクはその端末のファイルパスなので、他端末への配布には公開したHTTPSのURLを使用してください。

埋め込みフォニックスはオフラインで再生できます。単語・会話の再生は端末内の英語音声の有無に依存します。
Service Workerはサイト自身の範囲だけを扱い、他のGitHub Pagesサイトのキャッシュは変更しません。
更新を検出した場合は先生用設定から画面を更新できます。途中の問題は終了しますが、保存済み記録は残ります。

## Kahoot出力

Kahoot貼付TSVは7列の質問行です。公式のXLSXテンプレートの質問欄に貼り付けて保存します。TSVそのものを直接アップロードする形式ではありません。
問題文120文字以内、解答75文字以内、時間20秒、正解位置1〜4で出力します。画像はこの経路では含めません。
現在の形式は[Kahoot公式のインポート説明](https://support.kahoot.com/hc/en-us/articles/115002812547-How-to-import-questions-from-a-spreadsheet-to-your-kahoot)に合わせています。Kahootへの実際のアップロードは未検証です。
教材CSV・集計CSVは数式として解釈される文字列を無害化して出力します。

## 開発時の検証

Node.jsの標準機能だけを使用します。

```powershell
node --test tools/app.test.mjs
node tools/browser.test.mjs
```

ブラウザ検証にはローカルChromeを使用します。別の場所にある場合は`CHROME_PATH`を設定します。
検証は専用の一時プロファイルを使い、通常のブラウザの学習記録を変更しません。
画面キャプチャは実行結果に表示される一時ディレクトリに保存されます。
ブラウザ検証ではPC・タブレット・スマートフォンの9画面、学級ファイルの部分失敗、音声差し替えと保存、印刷、授業リンクを検証します。
オフライン検証時だけ専用の一時HTTPサーバーを起動し、終了時に停止します。
GitHub ActionsでもNode.js 24とChromeで同じ検証を実行します。アプリの配信時にNode.jsは必要ありません。

教材のIPAを変更した場合の音声再生成はWindowsで実行します。

```powershell
node tools/build-audio.mjs
```

生成時だけWindowsのSystem.Speechとインストール済みのen-US音声が必要です。
