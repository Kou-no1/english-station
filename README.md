# 星間通信局

小学3〜6年生向けの英語学習サイト。`index.html` を開くだけで使えます。
GitHub Pagesにもそのまま配置できます。配信時の外部ライブラリやビルドは不要です。

## 収録内容

- 語彙100語、10テーマ。絵・音声・フラッシュ・聞き取りクイズ。
- フォニックス44項目。基礎26文字、二重字・ブレンド、Magic e、母音チーム、単語くみたて。
- Small Talk 9テーマ。A/B役割交代と複数往復の対話。学校生活、夏の思い出、道案内、買い物を含みます。
- 表現24枚。発見と場面練習を別々に記録し、テーマごとにバッジを獲得します。

600〜700語をすべて収録した版ではありません。教科書に限定しない基礎教材です。

## 記録と授業設定

記録は端末のlocalStorageに保存します。既存v1の獲得記録を読み込みます。
獲得した星・ランク・バッジと、現在の復習状況を分けて保持します。
語彙の復習間隔は正解ごとに1・3・7・14・30日、誤答時は10分です。

先生用設定から再生速度・英語字幕・A/Bの声・投影モードを変更できます。
JSONで記録を書き出し、別端末に読み込めます。読み込みは内容確認後に現在の記録を置き換えます。
共有端末では児童ごとに別の記録ファイルを使用してください。

## 音声

フォニックスのWAV音声は、IPAを明示してMicrosoft Zira Desktopで生成し、HTML内に埋め込んでいます。
フォニックス音声の再生にネット接続は不要です。単語・会話にはブラウザのWeb Speech APIを使います。
声の種類と再生品質は端末によって異なります。先生用設定に全フォニックス音声の確認ボタンがあります。
合成音声であり、人による録音素材ではありません。

## 開発時の検証

Node.jsの標準機能だけを使用します。

```powershell
node --test tools/app.test.mjs
node tools/browser.test.mjs
```

ブラウザ検証にはローカルChromeを使用します。別の場所にある場合は`CHROME_PATH`を設定します。
検証は専用の一時プロファイルを使い、通常のブラウザの学習記録を変更しません。
画面キャプチャは実行結果に表示される一時ディレクトリに保存されます。

教材のIPAを変更した場合の音声再生成はWindowsで実行します。

```powershell
node tools/build-audio.mjs
```

生成時だけWindowsのSystem.Speechとインストール済みのen-US音声が必要です。
